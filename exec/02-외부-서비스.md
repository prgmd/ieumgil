## 1. 카카오 로그인 (OAuth 2.0)

서비스의 **유일한 인증 수단**이다. 자체 회원가입·비밀번호가 없다.

**가입** — [카카오 개발자센터](https://developers.kakao.com) > 로그인 > 내 애플리케이션 > 애플리케이션 추가하기

**설정 순서**

| 단계 | 위치 | 값 |
|---|---|---|
| ① 앱 키 확인 | 앱 설정 > 앱 키 | **REST API 키** 를 복사 |
| ② 카카오 로그인 활성화 | 제품 설정 > 카카오 로그인 | 활성화 ON |
| ③ Redirect URI 등록 | 제품 설정 > 카카오 로그인 > Redirect URI | `https://<도메인>/oauth/kakao/callback`<br>개발용 `http://localhost:5173/oauth/kakao/callback` 도 함께 등록 |
| ④ 동의 항목 | 제품 설정 > 카카오 로그인 > 동의항목 | **닉네임**, **프로필 사진** (필수 동의) |
| ⑤ Client Secret | 제품 설정 > 카카오 로그인 > 보안 | 사용 시 발급값을 `KAKAO_CLIENT_SECRET` 에 |

**넣을 곳**

```bash
# backend/.env
KAKAO_CLIENT_ID=<REST API 키>
KAKAO_CLIENT_SECRET=<Client Secret, 안 쓰면 빈 값>
KAKAO_REDIRECT_URI=https://<도메인>/oauth/kakao/callback

# frontend/.env (빌드 시점에 번들로 들어감)
VITE_KAKAO_REST_API_KEY=<REST API 키>       # OAuth client_id 와 같은 값
VITE_KAKAO_REDIRECT_URI=https://<도메인>/oauth/kakao/callback
```

**주의**

- Redirect URI 는 **끝 슬래시까지 정확히** 일치해야 한다. 하나라도 다르면 `KOE006`.
- 프론트의 `VITE_KAKAO_REST_API_KEY` 와 백엔드의 `KAKAO_CLIENT_ID` 는 **같은 값**이다.
  카카오 OAuth 는 REST API 키를 `client_id` 로 쓴다.
- **앱을 새로 만들어 옮기면 기존 회원이 전부 신규 가입자가 된다.** 카카오는 앱마다
  `kakaoId` 를 다르게 발급한다. 운영 중 앱 이전은 사실상 불가능하다.

## 2. 카카오맵 JavaScript SDK

**발급** — 1번과 같은 앱의 앱 설정 > 앱 키 > **JavaScript 키**

**필수 설정** — 앱 설정 > 플랫폼 > **Web** > 사이트 도메인에 `https://<도메인>` 등록

> 이 등록을 빠뜨리면 **로그인은 되는데 지도만 회색으로** 나온다. 도메인 검증에
> 걸린 것이라 콘솔에도 뚜렷한 에러가 안 남아 원인을 찾기 어렵다. 개발용
> `http://localhost:5173` 도 함께 등록해 둘 것.

**넣을 곳** — 환경 변수가 아니라 소스 상수다.

```
frontend/src/features/dashboard/map/addressLookup.js
  const KAKAO_APP_KEY = "<JavaScript 키>";
```

JS 키는 도메인 등록으로 사용처가 제한되므로 브라우저 노출이 정상적인 사용 방식이다.

## 3. 카카오 로컬 / 카카오모빌리티 REST API

장소 검색(`/v2/local/search/keyword`)과 도보·택시 경로 계산에 쓴다. **서버에서 호출**한다.

**발급** — 1번과 같은 앱의 **REST API 키**

**넣을 곳**

```bash
KAKAO_REST_API_KEY=<REST API 키>
```

`KAKAO_CLIENT_ID` 와 값은 같지만 **용도가 다르다.** OAuth 는 인증, 이쪽은 REST 호출
쿼터를 소모한다. 키가 없으면 장소 검색이 401/502 로 실패한다.

## 4. ODsay LAB

대중교통(버스·지하철·시외) 경로와 시간표. 교통수단 자동 추천의 핵심이다.

**가입** — [lab.odsay.com](https://lab.odsay.com) > 회원가입 > 마이페이지 > API 키 발급

무료 플랜에 **일일 호출 제한**이 있다. 개발 중 반복 호출로 소진되면 교통 추천이
502 로 실패하므로, 시연 전날 잔여량을 확인하는 편이 안전하다.

```bash
ODSAY_API_KEY=<API 키>
```

## 5. SSAFY GMS (Anthropic Claude 중계)

AI 챗봇 "이음이" 의 응답 생성. Spring AI 의 Anthropic 스타터가
`https://gms.ssafy.io/gmsapi/api.anthropic.com` 으로 요청을 보낸다.

**발급** — [gms.ssafy.io](https://gms.ssafy.io) 에서 팀 계정으로 발급

- 모델: `claude-haiku-4-5-20251001`
- max-tokens: 1024
- 재시도: 3회 (기본 10회는 실패 시 요청 스레드를 몇 분씩 붙잡음)

```bash
GMS_API_KEY=<GMS 키>
```

**팀 공용 크레딧을 소모한다.** 통합 테스트에서 실제 호출이 도는 것을 막기 위해
`@Tag("live")` 로 분리해 두었고, 기본 `./gradlew test` 에서 제외된다.
필요할 때만 `./gradlew test -PincludeLive`.

## 6. 공공데이터포털 TourAPI (선택)

축제·행사 정보와 홈페이지 링크.

**가입** — [data.go.kr](https://www.data.go.kr) > 회원가입 > "한국관광공사_국문 관광정보
서비스" 활용 신청 > 마이페이지 > 개발계정 상세

**⚠️ 인증키는 "Decoding" 값을 넣는다.** 마이페이지에 Encoding / Decoding 두 가지가
표시되는데, Encoding 값을 넣으면 클라이언트가 한 번 더 인코딩해 **이중 인코딩으로
401** 이 난다.

```bash
TOUR_API_KEY=<일반 인증키(Decoding), 특수문자 원본 그대로>
```

## 9. STUN 서버 (가입 불필요)

음성 채팅(WebRTC)의 NAT 통과에 Google 공개 STUN 을 쓴다.

```
stun:stun.l.google.com:19302
```

**TURN 서버는 없다.** STUN 만으로는 대칭형 NAT 뒤의 두 사용자를 연결하지 못한다.
같은 네트워크나 일반적인 가정용 공유기 환경에서는 동작하지만, **서로 다른 기관망
뒤에 있으면 음성이 연결되지 않을 수 있다.** 시연은 같은 네트워크를 전제한다.

해결하려면 coturn 등 TURN 서버를 세우고 `useVoiceChat.js` 의 `ICE_SERVERS` 에
자격증명과 함께 추가하면 된다.

## 10. Let's Encrypt (HTTPS)

음성 채팅(`getUserMedia`)과 초대 링크 복사(`navigator.clipboard`)가 **보안 컨텍스트를
요구**하므로 HTTPS 가 필수다.

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d <도메인>
sudo certbot renew --dry-run      # 자동 갱신 확인
```

인증서 경로 — `/etc/letsencrypt/live/<도메인>/fullchain.pem`, `privkey.pem`
