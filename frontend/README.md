# frontend

이음길 프론트엔드. React 19 + JavaScript(`.jsx`) + Vite.

## 스택

- 라우팅: react-router-dom 7
- 상태 관리: zustand
- HTTP: axios
- 실시간: @stomp/stompjs (WebSocket/STOMP)
- 지도: Kakao Maps JS SDK

## 실행

```bash
npm install
npm run dev      # 개발 서버 (/api → localhost:8080 프록시)
npm run build    # 프로덕션 빌드
npm run lint     # ESLint
```
